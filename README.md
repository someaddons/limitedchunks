# Limited Chunkloading

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_456640_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/456640.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Limited Chunkloading is a lightweight Minecraft mod which controls and limits loaded chunks to only stay X time after player logout.

- Cleans up loaded chunks (tickets) X minutes after a player logs off
- Also cleans up loaded chunks of mod's chunkloaders, add excluded ones to the config to disable

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
